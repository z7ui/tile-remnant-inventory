# v0.1.34 · 批量用掉 + 库存调整 + 多尺寸图示 + 一次确认

## 库存

- **用掉**：库存在卡片上直接「整砖批量使用」，一次扣 N 片。对应「来了 100 片 715，贴地板用了 50 片」，不用一片一片点。
- **调整**：手动把片数改成盘点后的实际值（写 adjust 流水，可溯源）。

## 多尺寸匹配

- 右上角入口改成**带边框和文字**的按钮（原来只有图标，看不出用途）。
- 结果里每块砖新增**混排图示**：外框是原砖，色块是每一片，不同尺寸不同颜色。
- 新增「**确认使用这 N 块**」：一次扣多块砖，每块按混排结果记账（一块只扣 1 块库存），扣完自动刷新。

## 后端

- `POST /inventory/{batch_id}/consume`：整砖批量使用。
- `POST /usage/confirm-multi`：多尺寸一次确认（事务内多块扣减 + 每块一条流水）。
- 容量校验：一块砖上所有片的面积之和超过砖面积会拒绝。
- 测试从 136 增加到 **143**（批量扣减、超扣拒绝、用完置 depleted、手动调整、多块确认、超容量拒绝）。

完整变更见仓库 `CHANGELOG.md`。

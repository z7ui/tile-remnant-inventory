# v0.1.5 · 入库成功提示改成大卡片

## 改了什么

确认入库成功后，原来是一条 SnackBar：

```
已入库 12 片                        [好的]
```

又矮又窄，而且**点内容区关不掉**——只有点那个小「好的」按钮才行。工地上单手操作，这个按钮很难命中。

现在换成底部大卡片：

- 60dp 圆形对勾 + **20sp 标题**「已入库 12 片」
- 副标题：尺寸 · 存放位置（例如 `600×600mm · 阳台左边`）
- 底部一行小字：点击任意处关闭
- **点卡片任意位置即消失**，也支持下拉关闭、点遮罩关闭
- 卡片关掉后才返回库存列表（原来是一入库就跳走，提示飘在列表上）

## 为什么不用对话框

对话框是模态的，会挡住整个页面。这张卡片只占底部一块，背景变暗但依然能看到库存列表——
连续录入时心里有数，不会觉得「我到底存进去没有」。

## 兼容

`showSavedCard` 放在 `widgets/common.dart`，其它页面（确认使用、匹配等）以后需要
「操作成功」反馈时可以直接复用，保证一致的观感。

版本 0.1.5+6。

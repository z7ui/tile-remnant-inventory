# v0.1.30 · 使用人数统计 + 里程碑礼炮

## 新增

- **关于页 · 使用人数**：显示当前有多少台设备在用、多少个项目，以及距离下一个里程碑还差多少人。
- **里程碑庆祝**：第 **10 / 100 / 1000 / 10000 / 100000** 位用户，进入关于页会放一场全屏礼炮 + 弹「恭喜你」窗口。
  - 只有注册时正好踩中节点的新设备才会触发，老设备升级不会补放；
  - 同一台机器只放一次，不会每次开关于页都弹。

## 后端

- 新增公开接口 `GET /api/devices/stats`：`{devices, projects, milestones}`。
- 设备注册返回 `device_ordinal`，命中里程碑时附带 `milestone`。

完整变更见仓库 `CHANGELOG.md`。

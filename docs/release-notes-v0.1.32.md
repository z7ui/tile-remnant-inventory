# v0.1.32 · 多尺寸一起匹配

快速匹配页右上角新增「多尺寸一起匹配」入口。

## 能做什么

- 一次输入最多 20 行尺寸 + 各自数量（例如 70×70 × 5、10×10 × 40）；
- 服务端按**大件优先**排序，在**同一块砖内**递归切割（一刀切到底）；
- 切完大件剩下的边条，**当场继续切小件**，不用等下一次匹配；
- 结果按「每块砖」展示：切了哪些尺寸各几片、利用率、浪费面积，以及满足/缺口统计。

## 说明

- 当前是**预览**：只算不扣库存，「确认使用（一次扣多块 + 余料入库）」下一步开放；
- L 形余料暂不参与混排（切法不唯一，避免算出切不出来的方案），会在结果里注明。

完整变更见仓库 `CHANGELOG.md`。
